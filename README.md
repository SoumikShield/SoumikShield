# Security is visibility.

An attacker doesn't always look like an attack.

Sometimes it's a login.

Sometimes it's a process.

Sometimes it's a DNS request.

Sometimes it's a configuration change.

Sometimes it's simply something that **doesn't belong**.

SoumikShield explores the defensive side of that problem:

**observe what is happening → understand why → detect what matters → respond intelligently → strengthen the system.**

# Responsible Security

<sub>17 / THE BOUNDARY</sub>

Research should be conducted only in isolated environments and against systems where permission has been granted.
