"05" — DETECTION ENGINEERING

A security alert is only useful when you can explain why it exists.

My investigation model:

          ALERT
            │
            ▼
      ┌───────────┐
      │ VALIDATE  │
      └─────┬─────┘
            ▼
      ┌───────────┐
      │  CONTEXT  │
      └─────┬─────┘
            ▼
      ┌───────────┐
      │ EVIDENCE  │
      └─────┬─────┘
            ▼
      ┌───────────┐
      │ TIMELINE  │
      └─────┬─────┘
            ▼
      ┌───────────┐
      │   SCOPE   │
      └─────┬─────┘
            ▼
      ┌───────────┐
      │ RESPONSE  │
      └───────────┘

Questions I want every investigation to answer:

«What happened?
How did it happen?
What evidence proves it?
What systems are affected?
How do we stop it from happening again?»
